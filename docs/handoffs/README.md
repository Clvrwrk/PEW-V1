# Handoffs

- `current.md` — the active project handoff. Always the latest.
- `archive/` — superseded handoffs.

## Process
When writing a new handoff: copy the existing `current.md` into `archive/` first, then overwrite `current.md` with the new one.

## Archive naming convention
`handoff_Date_Time.md` — e.g. `handoff_2026-05-04_0403.md` (date `YYYY-MM-DD`, time `HHMM`, from the archived handoff's own header timestamp). If two handoffs share a timestamp, append a disambiguating letter (`…0403b.md`).
